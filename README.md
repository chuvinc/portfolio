# Portfolio

A personal portfolio featuring Image Text Studio for browser-based OCR, image
cleanup, and lettering. The site showcases the application itself alongside the
technologies used to build, test, and deploy it.

## What It Includes

- A React frontend with project listings and build information.
- Image Text Studio, powered by Tesseract.js, WebAssembly, and OpenCV.js, with
  manually drawn OCR regions,
  confidence-aware region selection, mask-based text removal, preprocessing
  alternatives for difficult backgrounds, glossary corrections, and per-region
  replacement lettering.
- Editable, movable, resizable text boxes using the bundled CC Wild Words font,
  with alignment, weight, outline, size, and color controls. Enable
  `Clean image (text boxes only)` before uploading or dropping an already-clean
  image to add lettering without OCR or text removal.
- PNG exports from the `More` menu: `Download with text` includes lettering,
  while `Download Textless` exports the background generated by `Remove Text`
  without text layers. Clean-image uploads offer only the lettered download.
  Include all original text regions in the cleanup mask to remove all original
  text, and rerun `Remove Text` after changing the mask or solid fills.
- Browser-local image processing. Upload or drag and drop images; clipboard
  image importing is not supported. Extracted text can still be copied. The
  selected image stays in the tab while you work; `Clear Image` removes it.
- A small Node.js/Fastify API for project data and build metadata.
- Automated tests and GitHub Actions checks, plus GitHub Pages deployment with
  static snapshots of the API responses.
- Docker Compose for running the frontend and API together, with nginx serving
  the built frontend and proxying API requests.

## Project Layout

- `apps/web`: React/Vite frontend and OCR processing.
- `apps/api`: Fastify API.
- `.github/workflows`: checks and GitHub Pages deployment.

For local setup, test commands, and editor workflows, see
